Description complète

En tant que partenaire de l'agriculture, BISON veille à ce que les aliments suisses atteignent les consommateurs. Il est important que l'informatique soit adaptée de manière optimale aux besoins des domaines spécialisés. C'est exactement là que vous entrez en jeu en tant que spécialiste de l'intégration / développeur .NET Microsoft Azure*! Grâce à votre travail quotidien à Sursee, tout est coordonné avec l'entreprise et parfaitement aligné pour l'avenir. Vous souhaitez développer des solutions d'intégration modernes et développer davantage dans l'environnement Microsoft et Azure ? Alors vous avez raison avec nous.

Fais ça.

  • Développement et développement de solutions d'intégration avec les services d'intégration Azure (y compris les applications logiques, les fonctions Azure, la gestion des API, le bus de service)
  • Implémentation des interfaces et des workflows avec les applications logiques Azure
  • Développement de services et composants d'intégration avec fonctions Azure
  • Développer et déployer des API via Azure API Management
  • Mise en œuvre des intégrations de messagerie et d'événements avec Azure Service Bus
  • Développement des API REST et des services web avec ASP.NET Core et C#
  • Connexion de systèmes internes et externes via REST, messagerie et autres technologies d'interface
  • Analyse des besoins et élaboration de solutions techniques appropriées
  • Essais, dépannage et amélioration continue des intégrations existantes
  • Collaboration sur les thèmes architecture, sécurité et DevOps autour de notre plateforme d'intégration
  • Collaboration avec les ministères internes, les équipes d'application et les partenaires externes

C'est ce que vous apportez.

  • Plusieurs années d'expérience (minimum 3 ans) dans le développement de logiciels avec C# / .NET
  • Expérience des services d'intégration Azure, tels que bus service Azure, fonctions Azure, applications logiques ou gestion d'API
  • Connaissance des concepts de développement d'API (REST) et de messagerie
  • Expérience avec des formats de données structurés tels que XML ou JSON
  • Les avantages sont : l'expérience dans le développement web (par exemple ASP.NET Core, HTML, JavaScript), Git et CI/CD, Azure DevOps, OAuth 2.0 / OpenID Connect, conteneurs, Kubernetes ou d'autres technologies cloud-native, la surveillance et les informations d'application
  • Comprendre les concepts d'intégration et profiter de la résolution structurée des relations techniques
  • Travailleurs indépendants et méthodes de travail fiables
  • Vous avez un allemand élégant et de bonnes compétences en anglais pour la documentation technique
